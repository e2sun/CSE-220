# 💻 CSE 220: Systems Fundamentals I

This repository contains all programming projects completed for **CSE 220: Systems Fundamentals I** at Stony Brook University. The course explores foundational systems programming in C and MIPS assembly, covering memory management, bitwise operations, socket programming, and low-level data manipulation.

---

## 📁 Projects

### 🧩 Homework 0 – Basic Board Initialization in C
* File: `hw0_main.c`
* Description: Set up a static game board using 2D arrays and character elements to build familiarity with C syntax and memory layout.

---

### 🎮 Homework 1 – Interactive Terminal Game in C
* File: `hw1_game.c`
* Description: Built an interactive game where users take turns placing pieces on a board. Incorporated user input validation and win-condition checking with core game logic implemented in C.

---

### 📦 Homework 2 – PCIe Packet Parser and Memory Writer
* File: `hw2.c`
* Description: Implemented parsing and memory simulation for Transaction Layer Packets (TLPs) according to PCIe spec. Includes logic to interpret fields and store payload data into a simulated memory region.

---

### 🖼 Homework 3 – Image Compression with Quadtrees
* File: `hw3_main.c`
* Description: Processed grayscale PPM images using quadtree structures. Built functionality to convert image data to quadtrees, save/load the tree, and hide/reveal secret messages and images using steganography.

---

### 🌐 Homework 4 – Networked Battleship Server in C
* File: `hw4.c`
* Description: Created a server-side implementation of a multiplayer Battleship-style game using TCP sockets. Includes error handling, shape rotation logic, and game state management with Tetris-shaped ships.

---

### 🧮 Homework 5 – Tetris Simulator in MIPS Assembly
* File: `hw5.asm`
* Description: Simulated a simplified Tetris board using MIPS assembly. Includes tile placement, boundary checking, board printing, and piece validation logic using structured `.data` and `.text` sections.
